The Calendar page overflows at the bottom. Flutter's debug build shows
"BOTTOM OVERFLOWED BY 46 PIXELS" between the calendar grid and the monthly
stats row; in release the stripes go but the content is still clipped.

Observed on a macOS debug build at the default window size, on August 2026 --
a month that needs six week rows.

lib/calendar.dart hands TableCalendar a SizedBox of
MediaQuery.of(context).size.height * 0.57. TableCalendar has a fixed intrinsic
height (header + weekday row + up to six week rows), and 57% of the *window*
is not what the body was given: the app bar and the desktop navigation rail
have already taken their share, and the fraction accounts for neither. A
five-row month happens to fit, which is why it looks intermittent.

The column is already inside a SingleChildScrollView, so the box buys nothing.

Also assess lib/calendar.dart's day-detail bottom sheet, which uses the same
0.375-of-the-window idiom, and fix it only if it is genuinely the same defect.

Out of scope: the same idiom appears in ~20 other places under lib/. Do not
sweep them; file separately.
